# Threat model

Evaluate malicious pull requests, workflow modification, excessive FIC matching,
OIDC token replay, app-owner takeover, Graph permission escalation, tenant-root
role persistence, subscription vending abuse, policy exemptions, Terraform state
disclosure, compromised maintainers, and lost emergency access.

For each threat record the trust boundary, preventive control, detective control,
response, residual risk, and validation evidence.
