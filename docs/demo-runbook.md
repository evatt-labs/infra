# Identity-platform demonstration runbook

Build a short, repeatable narrative:

1. Show the tenant topology and permission matrix.
2. Inspect a GitHub OIDC token's non-sensitive claims.
3. Demonstrate exact FIC token exchange and scoped authorization.
4. Vend and place a subscription through separate billing/Azure permissions.
5. Show inherited policy and RBAC at the destination management group.
6. Activate a human eligible role through PIM when licensing is available.
7. Contrast GitHub federation with AKS service-account federation.
8. Show audit evidence and revoke temporary bootstrap access.

Prepare a plan-only fallback for every step that could incur cost or depend on a
preview/licensed feature.
